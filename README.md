# AI Agent Project

An intelligent AI agent built with Python, designed to help automate tasks and provide seamless API interactions.

## Features

- **AI-Powered Capabilities**: Integrates state-of-the-art language models and workflows.
- **Interactive API Documentation**: Access fully interactive API endpoints out of the box via Swagger UI.
- **Cross-Platform Support**: Simple installation and execution process on Windows, macOS, and Linux.

---

## Prerequisites

Before you begin, ensure you have the following installed on your system:
- **Python** (version 3.10 or higher recommended)
- **Git**

---

## Installation & Setup

Clone the repository and set up your environment by following the steps below based on your operating system.

### 1. Clone the Repository
```bash
git clone https://github.com/yourtoxic/SEC_outsiders_hackathon.git
```

### 2. Set Up a Virtual Environment & Install Dependencies

#### **Windows**
Open Command Prompt (`cmd`) or PowerShell and run:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

#### **macOS & Linux**
Open your terminal and run:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

---

## Running the Application

Once your dependencies are installed and your virtual environment is activated, you can start the application using the following command:

```bash
python -m app.main
```

---

## Accessing the API & Documentation

After starting the application, open your web browser and navigate to:

- **API Documentation (Swagger UI):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
